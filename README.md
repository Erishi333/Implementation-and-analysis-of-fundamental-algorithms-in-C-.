# 🚀 C++ Algorithm Lab

Un proyecto educativo donde estoy practicando e implementando **algoritmos fundamentales**, **análisis de complejidad computacional** y **resolución de problemas** usando C++.

---

## 📋 Contenido del Proyecto

### 🔍 Algoritmos de Búsqueda
- **Búsqueda Lineal** - O(n)
- **Búsqueda Binaria** - O(log n)
- **Búsqueda Binaria Recursiva** - O(log n)

### 📊 Algoritmos de Ordenamiento
- **Ordenamiento Burbuja** - O(n²)
- **Ordenamiento por Selección** - O(n²)
- **Ordenamiento por Inserción** - O(n²)

### 🔄 Recursión
- Problemas y patrones de recursión (en desarrollo)

---

## 🛠️ ¿Cómo compilar y ejecutar?

### Requisitos previos:
- **g++** (compilador de C++)
- **make** (gestor de compilación)

### Comandos:

```bash
# Clonar el repositorio
git clone https://github.com/Erishi333/Implementation-and-analysis-of-fundamental-algorithms-in-C-.git
cd Implementation-and-analysis-of-fundamental-algorithms-in-C-.

# Compilar
make

# Ejecutar
make run

# Limpiar archivos compilados
make clean

# Ver todas las opciones disponibles
make help
```

## 📊 Análisis de Complejidad

| Algoritmo | Mejor Caso | Caso Promedio | Peor Caso | Espacio |
|-----------|-----------|---------------|-----------|---------|
| **Búsqueda Lineal** | O(1) | O(n) | O(n) | O(1) |
| **Búsqueda Binaria** | O(1) | O(log n) | O(log n) | O(1) |
| **Burbuja** | O(n) | O(n²) | O(n²) | O(1) |
| **Selección** | O(n²) | O(n²) | O(n²) | O(1) |
| **Inserción** | O(n) | O(n²) | O(n²) | O(1) |
